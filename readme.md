# Toolbars Mod

Toolbars Mod enhances your Factorio interface with flexible toolbar management, export/import support, and advanced item tooltips.

## Description

This mod provides customizable toolbars with sections, lockable layouts, and a wide range of usability improvements. It includes:

- toolbar export/import features
- exact toolbar position and state preservation
- item tooltip enhancements with inventory, logistic network, and crafting information
- support for various inventories including character, editor, car, tank, Spidertron, and space platform hub
- Spidertron remote support and Factorio 2.1 compatibility
